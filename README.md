# Geografi i rörelse

En enkel presentationssida med svenska, engelska, ukrainska och ungerska versioner av **Kartkunskap och Jordens inre och yttre krafter**.

## Användning

Välj språk, bläddra med knapparna eller piltangenterna och använd **Helskärm** vid genomgång. Animationerna spelas automatiskt. **Visa stillbild** ger en lugn bild att läsa. **Dela bild** kopierar en direktlänk som kan klistras in i OneNote.

Alla 23 bilder finns i varje språkversion. De ursprungliga GIF-filerna används direkt och behåller sina bildrutor och tidsintervall. Bildplacering och beskärning följer presentationen. Endast animationen på den valda bilden laddas.

## Publicering och lokal körning

Sidan använder vanlig HTML, CSS och JavaScript utan externa bibliotek, konton eller spårning. GitHub Pages publicerar `main` från rotkatalogen. Öppna sidan via en webbserver lokalt, till exempel `python -m http.server 8080`.

`slides.js` innehåller bildtitlar, text och GIF-placeringar. `sv-`, `en-`, `uk-` och `hu-` anger språk. Originalmaterialets eventuella bildrättigheter och källangivelser gäller även här; ingen ny licens har lagts på undervisningsmaterialet.
